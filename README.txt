ТАНКОВЫЙ ФРОНТ — Android PWA-пакет

ВАЖНО: PWA-функции (установка как приложения и офлайн-кэш) работают после размещения на HTTPS-хостинге. Нельзя просто открыть index.html локально и ожидать установки PWA.

Файлы:
- index.html — игра
- manifest.webmanifest — имя, иконка и настройки установки
- sw.js — кэш для офлайн-запуска после первого открытия
- icon.svg — иконка

Как использовать:
1. Разместить все файлы из папки на HTTPS-хостинге, сохранив структуру.
2. Открыть URL на Android в Яндекс Браузере.
3. В меню браузера выбрать «Добавить на главный экран» (название пункта может отличаться).
4. Запустить игру с появившейся иконки.
5. После первого успешного открытия проверить офлайн-режим.

Прогресс игры хранится в локальном хранилище браузера. Для переноса используйте встроенные кнопки экспорта/импорта сохранения.
